# real_landing · 飞机降落

难度：L3。来源：2023 省赛 C/C++ B 组；https://www.luogu.com.cn/problem/P9241。

## 要交付什么

题意简述：输入测试组数 T≤10，每组 n≤10，随后 n 行 arrival wait duration（均为 0..10^5）。单跑道不可同时降落；每架必须在 [arrival,arrival+wait] 内开始。输出能否全部安排 YES/NO。

## 自测样例（本仓库自编）

输入：
```text
2
2
0 0 2
2 0 1
2
0 0 2
0 0 2
```
输出：
```text
YES
NO
```

枚举降落顺序。已定顺序时每架尽早开始不会使后面的飞机更差；开始时刻 max(now,arrival)。若超过最迟开始时刻则剪枝。

复杂度：最坏时间 O(n·n!)，空间 O(n)。

容易错在：约束的是开始时间而非结束时间；排序一次的贪心一般不正确。


### 搜索树是什么样

样例第一组中，先选飞机 1：它必须在 0 开始，2 时刻结束；飞机 2 在 2 时刻开始，3 时刻结束，所以输出 YES。反过来先选飞机 2，飞机 1 到 3 时已错过最迟开始时刻 0，这条分支失败。

```text
开始 now=0
├─ 选飞机1：start=0，结束=2 → 选飞机2：start=2，成功
└─ 选飞机2：start=2，结束=3 → 飞机1最迟0，失败
```

对于每个部分顺序，`used[i]` 表示是否已安排，`now` 表示跑道什么时候空出来。下一架的最早开始是 `max(now, arrival[i])`：跑道空了也要等飞机来，飞机来了也要等跑道空。这个开始时刻如果超过 `arrival+wait`，这条选择一定失败。

**为什么固定顺序后尽早开始就够？** 在相同顺序下，前一架延后只会使其后飞机可用时间不早于现在，不会创造额外空间。回溯时标记 used、尝试下一层、失败后撤销；成功可以直接返回。不要把最迟开始误读成最迟结束，例如 (arrival=3, wait=0, duration=100) 仍可在 3 时开始。
