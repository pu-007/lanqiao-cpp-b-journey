# real_weights · 砝码称重

难度：L3。来源：2021 第一轮省赛 A/B 共享题；https://www.luogu.com.cn/problem/P8742。

## 要交付什么

题意简述：n≤100 个砝码，总重 S≤10^5，每个可放左边、右边或不用，求能称出的不同正重量数量。输入 n 和 n 个重量，输出数量。

## 自测样例（本仓库自编）

输入：
```text
2
2 3
```
输出：
```text
4
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start real_weights` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check real_weights --mine`；失败时先缩小反例。
5. 通过后再读 [real_weights.cpp](real_weights.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

dp[d] 表示已处理砝码可实现的绝对重量差 d。新砝码 w 对每个旧 d 产生 d、d+w、|d-w|。必须从旧数组转移到新数组，不能同轮反复使用一个砝码。

复杂度：时间 O(nS)，空间 O(S)。

容易错在：不计 0；只做普通子集和会漏掉放两侧的方案。

</details>

## 升级练习

- 真题迁移：用 3^n 枚举每个砝码的三种状态，核对小输入。
- 扩展：用带偏移的有符号重量差 DP，比较与绝对值状态的关系。

验收：能说明改变哪个约束会使当前算法失效，补一个原样例没有覆盖的边界。升级练习是开放扩展，不包含独立参考答案与自动评测；主任务有参考实现和本地测试。
