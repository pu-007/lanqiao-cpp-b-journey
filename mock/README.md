# 限时训练与模拟赛

历史整套入口在 [past-papers.md](../resources/past-papers.md)。2025、2026 省赛留到 W23/W24，正式开始前不要看标签、题解或参考代码。如果已经做过，标为 seen，改用未做过的同组试卷；不能把复现成绩当成盲测。

## 120 分钟本地关卡（W21）

这些题学过，测的是复写稳定性，**不是陌生题能力**。关闭项目代码，用独立空文件作答：

| 时间建议 | 题目 ID | 检查什么 |
| --- | --- | --- |
| 0–15min | ranking | STL 与稳定实现 |
| 15–35min | prefix | 边界与类型 |
| 35–65min | capacity | 判定与二分 |
| 65–95min | knapsack | DP 层次 |
| 95–120min | maze 或 real_smelting | 建模、调试、提交检查 |

不设虚构官方分值。记录 5 题各自是否独立完成、耗时和错因；目标是至少 4 题完整正确，未达到就先修复基础，不急着攻更难内容。

## 4 小时历史整套流程

前 10–15 分钟浏览全部题，标注“会做、可尝试、暂不做”，再分配时间。先完成确定性高的题，中途每 45–60 分钟重新评估卡题收益。最后 20–30 分钟用于检查编译器、输入格式、大整数、数组上界与提交文件。

现场反馈方式以当届规程为准。做历史模拟时可先冻结最终提交再跑 OJ，以减少即时评测带来的额外提示。部分分只在题目确有评分规则且评测平台能提供时记录；本地小数据正确不能冒充官方部分分。

没有原始分数表时只统计“完整通过题数、可验证子任务、未完成题”；不随意把每题按 100 分相加，再换算成国一概率。

## 模拟后 3 小时必须做的事

先用 [模板](../templates/mock-review.md)记下时间去向。选一道“本来能做却错了”的题修实现，再选一道“差一个模型”的题学迁移。对真正超出现阶段的压轴题只读主要思路，不挤掉主线训练。

把本次最小反例加入自己的测试。48 小时后关闭题解复写；下一周重做同一模型的陌生变式。反复发生的错误才是下一周优先级最高的任务。
