# 从 2026-10-21 到 2027 年四月的周计划

按你确认的 **每周 8–10 小时**设计。2027-04-15 是计划锚点，不是已确认的官方比赛日期；共约 25 周加最后 2 天，约 200–250 小时。四月目标是省赛，国一属于后续全国总决赛目标。赛日若提前，删掉最后的新专题，把两次盲测前移。

## 每周怎样用 9 小时

普通周：2h 学模型与纸笔推演；2h 完成一个主任务；2h 独立变式或真题；1.5h 重做旧题；1.5h 总结与补欠。安排到哪几天由你决定。选做项只能用剩余时间，不得挤掉复习。

模拟周：4h 连续模拟，2h 分析失分，2h 修复一道关键题，1h 重做。没有连续 4h 时可做 2×2h 分段练习，但必须标为分段，不能与完整限时成绩直接比较。

主线约每周 1–2 道新模型/任务，真题迁移与重做按实际速度安排。不要承诺每周十几题。延期时先取消选做，再把一个提高专题挪到省赛后，保留 STL、基础算法、BFS、背包、基本图论及两次盲测。

## 什么时候升级

11 月中旬：无需查表写 vector/sort/map/queue 基本操作。12 月中旬：能从约束区分 O(n²) 与 O(n log n)，独立完成窗口和二分。1 月下旬：能定义简单 DP 状态，并写 DFS/BFS。2 月下旬：能区分图论三类目标。3 月：把模型迁移到陌生题并进行整套训练。

一个门槛连续两周没达到，就回退一层，用具体错题补课；不要靠读完下一章制造进度。
