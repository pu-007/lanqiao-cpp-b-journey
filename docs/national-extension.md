# 国赛补充任务：主线稳定后再做

34 个示例覆盖主要入门与提高模型，但不是所有国一可能涉及的知识。以下是补齐宽度的开放实验，**未附完整实现与自动测试**。只在对应模型需要时推进，不要求四月前全做完。

| ID | 项目需求与输入输出 | 先修 | 验收 |
| --- | --- | --- | --- |
| X1 | 区间加/区间和：n q、n 个初值；`1 l r d` 区间加，`2 l r` 输出和；n,q≤2e5，值与增量绝对值≤1e9 | fenwick、递归 | 懒标记线段树；每次和数组暴力对拍 |
| X2 | 树距离：n q、n-1 条 u v w；q 个 u v 输出距离；n,q≤2e5，0≤w≤1e9 | dsu、树遍历 | 倍增 LCA + 根距离；深链、星形树都过 |
| X3 | 依赖任务：n m、n 个非负工期、m 条前置边 u→v；并行执行，输出最早全部完成时间，有环输出 -1 | queue、图表示、DP | Kahn 拓扑序 + 最长路 DP；能检出环 |
| X4 | 装备选择升级：n≤40，目标 K≤1e12，非负重量，输出恰好和为 K 的子集数 | subsets、二分 | 折半搜索；重复和保留次数，计空集 |
| X5 | 多次区间最小值：n q≤2e5，静态数组，查询 [l,r] 最小值 | prefix、二进制 | sparse table；解释为何允许两块重叠 |
| X6 | 最多选 k 次字符匹配：两个小串长≤200，求最长公共子序列 | knapsack、lis | 先写标准二维 LCS；再自行定义限制变式 |

## X1 的具体起步

输入：
```text
3 3
1 2 3
2 1 3
1 1 2 4
2 2 3
```
输出：6、9，各一行。对区间整体加 d，节点和增加 `d*区间长度`；懒标记表示对子节点尚未下发的统一增量。先实现“单点改+区间和”，再引入懒标记，别一口气写完整泛型库。

## X2 的具体起步

边 1-2 权 3，2-3 权 4：distance(1,3)=7，distance(2,2)=0。先 O(n) 找父链交点，再做倍增；公式 `dist[u]+dist[v]-2*dist[lca]` 的重叠部分要画出来。迁移题可看 2023 省 B“景区导游”，其完整额外条件以原题为准。

## X3 的具体起步

任务工期 [2,3,5]，边 1→3、2→3：最早完成为 8，不是总工期 10。增加 3→1 后有环。定义 finish[v] 为完成 v 的最早时刻，所有前置任务均结束后才能开始。

## 数学与字符串继续补什么

gcd/因数分解/模逆元/组合计数先于复杂数论。坐标题先用整数平方距离避免浮点误差，确认乘法范围。字符串先熟悉双指针、前缀函数；哈希要理解碰撞和验证，不能当绝对正确的黑盒。

后续依据错题选择 0-1 BFS、Floyd、拓扑 DP、差分约束、Trie、矩阵快速幂等；无需为了“国一”三个字现在就全面学习网络流、后缀数组或树链剖分。查阅 [OI Wiki](https://github.com/OI-wiki/OI-wiki) 的对应章节，再回到一道具体题验证。
