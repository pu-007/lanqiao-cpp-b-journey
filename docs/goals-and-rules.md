# 目标、赛制与现实边界

## 你的起点如何影响路线

多语言开发经验可帮助你理解输入处理、调试、模块边界和自动化验证；竞赛新增的难点是“从约束推出算法”“证明不会漏解”“控制复杂度”。因此不安排长篇面向对象、模板元编程或系统工程课程；先掌握标准库够用的部分，再学习算法状态与不变量。

主语言选 C++。C/C++ 赛道并不要求每题都分别写 C 和 C++；STL 能减少容器代码量。C 的基础语法仍然有用，但没有必要为了参赛手写所有链表、平衡树和堆。

## 国一方向的可检查能力

| 层级 | 能力门槛（本仓库自定，非官方标准） |
| --- | --- |
| 基础稳定 | 20–30 分钟内独立写常见枚举、排序、前缀和；主动测边界 |
| 省赛核心 | 对陌生描述能识别二分、搜索、DP、图模型；会估算时间和空间 |
| 国赛提高 | 一题需要两个模型时能拆解；能处理状态设计、离线、树形与区间依赖 |
| 实战成熟 | 限时能取舍、先实现可证明的基线，复盘能找出重复错误并闭环 |

8–10h/周到四月约 200–250h，足以建立扎实体系，但国一还受实际学习速度、比赛发挥与同场水平影响。优先提高独立解决陌生题的能力，不把“看懂了 100 份题解”当成达标。

- [长江大学通知](https://sfzx.yangtzeu.edu.cn/info/1058/1953.htm)提及省一入围总决赛，但页面赛事年份与部分时间字段存在矛盾，不据此锁定具体赛日。
- [官方入口](https://dasai.lanqiao.cn/)本次文本抓取未读到完整动态内容，因此没有核实 2027 精确省赛/国赛日期、编译器版本和资格细则。

## 你在报名时需要核对

学校是否有校内选拔、B 组资格、院校报名流程和校内截止日；当届正式比赛日期、编译器选项、是否允许自带资料、提交方式。不要把别的学校的校内截止日套用到自己。

仓库以 2027-04-15 为备赛锚点，省赛后继续 6–8 周滚动强化。国一是全国总决赛奖项，四月这一步应先争取晋级。没有可靠依据时，不给“多少分必国一”的结论。
