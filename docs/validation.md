## 对拍怎么做

背包/子集/LIS 用子集枚举；容量规划枚举全部切分点；会议选择枚举会议子集；TSP 枚举全排列；最短路用反复松弛；MST 枚举小图所有可能生成树；桥和带权删边逐边删除后遍历连通分量；子矩阵枚举四边界并直接求和。这样尽量避免拿同一份算法重写一次互相验证。

图随机数据包含自环、重边、不连通；数组含重复、负值或零（遵守各题范围）。边界检查覆盖大整数总和、全零窗口计数、20 万点深链、10^18 数位上界、500×500 全零矩阵。

复现命令：

```bash
python3 scripts/lab.py check all
python3 scripts/verify.py --seed 20261021 --rounds 40
```

逐题检查次数保存在 [verification-report.json](../tests/verification-report.json)。重新运行产生的报告位于 build/verification.json，不覆盖交付记录。

测试不构成形式化证明，也没有验证所有外部题解、所有平台编译器或官方隐藏数据。每题文档给出使用前提、复杂度和边界，学习时仍需自己解释正确性。
