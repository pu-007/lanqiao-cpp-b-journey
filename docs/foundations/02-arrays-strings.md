# 02 · 数组和字符串：算法最常见的材料

## 把数组想成一排带编号的格子

```text
下标 i:    0   1   2   3
值 a[i]:   4   7   7   1
```

C++ 的 `vector` 从 0 开始编号，4 个元素的有效下标是 0、1、2、3；访问 a[4] 越界。数组是“有顺序的一组值”，可以出现相同的 7。

```cpp
#include <iostream>
#include <vector>
int main() {
    std::vector<int> a = {4, 7, 7, 1};
    int count = 0;
    for (int x : a) {            // 从左到右逐个取值
        if (x == 7) ++count;     // 每遇到一个 7 加一
    }
    std::cout << count << '\n'; // 输出 2
}
```

这次用的是 `x` 的副本。若写 `for (int& x : a)`，x 是原元素的引用，修改 x 会修改数组；用 `const int&` 可只读且避免复制大对象。

## 把“查找”和“计数”区分开

找有没有：遇到 7 就可以停；数有几个：必须继续扫完整个数组。上例中若遇到第一个 7 就 `break`，答案会错误地变成 1。

值域很小时，可用下标代表数字：`count[x]++`。例如输入分数均为 0..100，可以准备 101 个计数格；若分数可能是 −10⁹ 或 10⁹，就不能直接开这么大的数组。值域巨大但不同值不多时可考虑 `map` 或 `unordered_map`。

## 排序不是魔法：先说明顺序

默认 `sort(a.begin(), a.end())` 从小到大，上例变 `[1,4,7,7]`。排序会改变原顺序，所以题目若要求原始位置，需要额外保存下标。排序之后相同元素相邻，便于去重或统计；不要在题目不允许改变运输顺序时先排序。

重复值统计示意：

```text
排序后： 1  4  7  7
                  ↑  ↑   相同值相邻，出现两次
```

## 字符串：字符组成的序列

`std::string s = "abc";` 中 `s[0]` 是字符 `'a'`。单引号 `'a'` 表示字符，双引号 `"a"` 表示字符串。`s.size()` 为长度；遍历通常写 `for (char c : s)`。

`std::cin >> s` 读一个以空白分隔的单词，`std::getline(std::cin, s)` 读整行、可包含空格。先用 `cin >> n` 再 `getline` 时，前一次输入留下的换行可能被读成空行；可用 `cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n')` 丢弃当前行余下内容，需 `#include <limits>`。如果题目允许空行作为数据，不要无条件用 `std::ws` 跳过它。

本仓库多数题以 ASCII 英文字母、数字为输入；UTF-8 中文通常由多个字节组成，`string::size()` 统计字节数，不是中文字数。

**常见误区**：`reserve(10)` 只预留空间，不能立刻访问 `v[0]`；`vector<int> v(10)` 才创建了 10 个元素。读取/修改时要确认下标有效。
