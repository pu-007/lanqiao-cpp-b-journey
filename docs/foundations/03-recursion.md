# 03 · 递归与回溯：把任务交给更小的自己

## 从求和开始

计算 `1+2+3` 可以拆成 `3 + (1+2)`，而 `1+2 = 2+(1)`。这个关系可以写成 `sum(n)=n+sum(n-1)`。但必须规定什么时候停止：`sum(0)=0`。

```cpp
#include <iostream>
long long sum(int n) {
    if (n == 0) return 0;       // 终止条件：不能再继续拆
    return n + sum(n - 1);      // 相信较小规模的调用会返回正确答案
}
int main() { std::cout << sum(3) << '\n'; }
```

运行时像叠盘子：

```text
向下调用: sum(3) → sum(2) → sum(1) → sum(0)
向上返回:    6   ←    3   ←    1   ←    0
```

每次调用都有自己的 n。返回结果后上一层才继续。漏掉终止条件、或参数不朝终点变化，会导致无限递归/栈溢出。大输入求和应使用循环或数学公式，上面的递归只用来理解调用过程。

## 回溯：依次尝试选或不选

有两件物品 A、B，要列出所有选择。先对 A 做决定，再对 B 做决定：

```text
                开始
          不选 A     选 A
          /   \       /   \
      不选B  选B   不选B  选B
         ∅    B      A    AB
```

程序中的“状态”包括处理到哪件、已经选了什么。每一步选择后进入下一层，返回时再试另一条路。若当前选择记录在共享容器中，回来后要撤销，防止影响下一条分支：

```cpp
#include <iostream>
#include <vector>
void visit(int i, std::vector<int>& path) {
    if (i == 2) {                 // 两件物品都决定完了
        for (int x : path) std::cout << x << ' ';
        std::cout << '\n';        // 空行代表空集
        return;
    }
    visit(i + 1, path);           // 不选编号 i 的物品
    path.push_back(i);             // 选择
    visit(i + 1, path);
    path.pop_back();               // 撤销，使同层的其他分支看见原状态
}
int main() { std::vector<int> path; visit(0, path); }
```

`path` 是引用，因此同一个容器被各层共享。若状态改为按值传递（比如整数 sum），每一层得到副本，通常不用手动撤销。n 件独立物品各有两种选择，可能有 2ⁿ 个叶子，先看 n 是否足够小。

## 剪枝为什么需要条件

若重量都非负、目标重量是 10，当前和已经是 12，则后面再选物品也不可能回到 10，可以停止这一分支。如果允许负重量，后面可能选 −2 变回 10，就不能这样剪枝。**每条剪枝都要说清楚为什么不会删掉合法答案。**
