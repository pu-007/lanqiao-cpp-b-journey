# 算法基础：从会写代码到看懂题目

给已经学过基本语法、但第一次系统学习算法的人。每节按“生活例子 → 手算 → C++ 小代码 → 自己试”安排；建议每次学 40–60 分钟，遇到不熟悉的词先回到这页。

1. [复杂度：程序为什么会超时](01-complexity.md)——估算循环次数和内存。
2. [数组与字符串：数据怎么存](02-arrays-strings.md)——下标、遍历、计数、排序。
3. [递归与回溯：把大任务拆小](03-recursion.md)——调用栈、返回、选择与撤销。
4. [调试与测试：怎么找出错误](04-debugging.md)——最小反例、边界和对拍。
5. [常见算法的直观讲解](algorithms.md)——枚举、排序、二分、前缀和、双指针和贪心。
6. [搜索、动态规划和图](dp-graphs.md)——从选或不选到 BFS、背包和最短路。

[12 道基础练习](practice.md) 配独立参考代码，先做自己能完成的题；[离线交互演示](../../visualizations/index.html) 可以单步观察前缀和、二分和 BFS；[可视化网站清单](../../resources/visual-learning.md) 用于观察更多算法。

每节结尾都连接仓库现有任务。别急着背代码：先盖住答案在纸上重画示例，能解释每个变量，再动手运行。`O(n)`、递归等概念第一次不熟很正常，结合对应题回来读第二遍。

配套的 [STL 入门](../stl.md) 解释容器用法；[算法建模笔记](../algorithm-thinking.md) 适合学完这里之后复习。练习先做基础主任务，开放扩展可以暂时跳过。
