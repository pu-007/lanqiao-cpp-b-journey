# dijkstra · 校园快递最短路

难度：L3。来源：原创教学题。

## 要交付什么

输入 n m s（1≤n≤200000，0≤m≤300000，1≤s≤n）；接着 m 行 u v w 为有向边，0≤w≤10^9。输出从 s 到每个点的最短距离，不可达为 -1。允许重边、自环。

## 自测样例（本仓库自编）

输入：
```text
4 4 1
1 2 10
1 3 1
3 2 2
2 3 0
```
输出：
```text
0 3 1 -1
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start dijkstra` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check dijkstra --mine`；失败时先缩小反例。
5. 通过后再读 [dijkstra.cpp](dijkstra.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

每次取暂定距离最小的点，非负边保证这个距离不会被未处理点改小。优先队列支持重复入堆，用距离数组识别过期状态。

复杂度：时间 O((n+m) log(n+m))，空间 O(n+m)。

容易错在：负边不能用 Dijkstra；priority_queue 默认最大堆；过期项必须跳过。

</details>
