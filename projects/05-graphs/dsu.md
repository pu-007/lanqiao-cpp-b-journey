# dsu · 好友圈连通性

难度：L2。来源：原创教学题。

## 要交付什么

输入 n q（1..200000），接着 q 行 op u v，点编号 1..n。op=1 合并两个圈子，op=2 查询是否连通，输出 YES/NO。

## 自测样例（本仓库自编）

输入：
```text
4 5
2 1 2
1 1 2
1 2 3
2 1 3
2 1 4
```
输出：
```text
NO
YES
NO
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start dsu` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check dsu --mine`；失败时先缩小反例。
5. 通过后再读 [dsu.cpp](dsu.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

每个集合用一棵父指针树表示，根相同即同集合。路径压缩把访问过的点直接接到根；按大小合并避免瘦长树。

复杂度：均摊时间 O((n+q)α(n))，空间 O(n)。

容易错在：合并的是根；普通并查集不支持删除边。
