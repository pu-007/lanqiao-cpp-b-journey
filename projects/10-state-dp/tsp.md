# tsp · 小型配送路线

难度：L4。来源：原创教学题。

## 要交付什么

输入 n（1≤n≤17）与 n×n 的非负费用矩阵（每项≤10^9，主对角为 0）。从编号 0 出发，每个点恰好访问一次后回到 0，求最小费用；n=1 输出 0。

## 自测样例（本仓库自编）

输入：
```text
3
0 2 9
2 0 3
9 3 0
```
输出：
```text
14
```

## 从全排列到状态压缩

最直接枚举除起点外所有点的访问顺序，算每条路线的费用，取最小。n=17 时有 16! 种顺序，远超可承受范围。观察到：如果已经访问的点集合相同、当前位置相同，后续可选的点一样；其中花费更大的历史没有必要保留。

`dp[mask][u]` 保存“已经访问集合 mask、现在停在 u”的最小费用。二进制第 v 位为 1 表示访问过 v；例如 3 个点时 `011` 代表已访问 0、1。每次选择一个尚未访问的点 v，把第 v 位设为 1 并更新成本。注意不同终点仍需分开存，不能只记 mask。

## 样例逐步推演

从 0 出发：`dp[001][0]=0`。走到 1 后 `dp[011][1]=2`；再到 2 成本是 `2+3=5`，回到 0 再加 9，合计 14。另一条路线 `0→2→1→0` 的成本为 `9+3+2=14`，因此输出 14。

终态是所有点都访问后，再加回起点的费用；若漏掉这一步，就会把样例错误算为 5。本题点数至多 17 才能使用 O(n²2ⁿ) 的状态压缩；当点数为 100 时，状态空间已经不可行，必须根据新题条件找其他方法。

<details><summary>提示与推导（先尝试再展开）</summary>

状态 dp[mask][u]：访问集合恰为 mask，终点为 u 的最小成本。mask 用二进制位表示访问集合；每次加入一个未访问点。最终还要付返回 0 的成本。

复杂度：时间 O(n²2^n)，空间 O(n2^n)，n=17 时 DP 约 17 MiB。

容易错在：位运算测试写括号；状态数随 n 指数增长，不可用于 n=100。
