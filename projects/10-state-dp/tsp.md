# tsp · 小型配送路线

难度：L4。来源：原创教学题。

## 要交付什么

输入 n（1≤n≤17）与 n×n 的非负费用矩阵（每项≤10^9，主对角为 0）。从编号 0 出发，每个点恰好访问一次后回到 0，求最小费用；n=1 输出 0。

## 自测样例（本仓库自编）

输入：
```text
3
0 2 9
2 0 3
9 3 0
```
输出：
```text
14
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start tsp` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check tsp --mine`；失败时先缩小反例。
5. 通过后再读 [tsp.cpp](tsp.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

状态 dp[mask][u]：访问集合恰为 mask，终点为 u 的最小成本。mask 用二进制位表示访问集合；每次加入一个未访问点。最终还要付返回 0 的成本。

复杂度：时间 O(n²2^n)，空间 O(n2^n)，n=17 时 DP 约 17 MiB。

容易错在：位运算测试写括号；状态数随 n 指数增长，不可用于 n=100。

</details>
