# digit_dp · 超大数字筛选器

难度：L4。来源：原创教学题。

## 要交付什么

输入 N（0≤N≤10^18），输出 [0,N] 内十进制表示不含数字 4 的整数数量。0 计入。

## 自测样例（本仓库自编）

输入：
```text
20
```
输出：
```text
19
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start digit_dp` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check digit_dp --mine`；失败时先缩小反例。
5. 通过后再读 [digit_dp.cpp](digit_dp.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

把 N 当作上界字符串，状态 (pos,tight) 表示前缀是否贴着上界。下一位只枚举允许数字。因为前导 0 不影响“是否含 4”，本题无需 started；换成统计数字 0 时就必须重新定义。

复杂度：时间 O(位数×10)，空间 O(位数)。

容易错在：把位数不足的数补前导 0，只对某些性质安全；本题包含数字 0。

</details>
