# prefix · 静态区间报表

难度：L1。来源：原创教学题。

## 要交付什么

输入 n q（1..200000），n 个绝对值≤10^9 的整数，随后 q 行 l r（1≤l≤r≤n）；每行输出闭区间 [l,r] 的和。

## 自测样例（本仓库自编）

输入：
```text
4 3
2 -3 5 7
1 4
2 2
3 4
```
输出：
```text
11
-3
12
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start prefix` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check prefix --mine`；失败时先缩小反例。
5. 通过后再读 [prefix.cpp](prefix.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

定义 s[i] 为前 i 项之和，s[0]=0。两个前缀的重叠部分抵消，得到 s[r]-s[l-1]。

复杂度：时间 O(n+q)，空间 O(n)。

容易错在：统一使用 1-based；静态前缀和不支持快速修改。

</details>
