# window · 预算内连续训练段

难度：L2。来源：原创教学题。

## 要交付什么

输入 n K（1≤n≤200000，0≤K≤10^14）和 n 个 0..10^9 的整数。输出元素和≤K 的非空连续子数组数量。

## 自测样例（本仓库自编）

输入：
```text
4 3
1 2 0 3
```
输出：
```text
8
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start window` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check window --mine`；失败时先缩小反例。
5. 通过后再读 [window.cpp](window.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

固定右端点 r。由于元素非负，左端点右移只会使和变小；找到最左合法 l 后，以 r 结尾的合法区间正好有 r-l+1 个。每个端点只移动 n 次。

复杂度：时间 O(n)，空间 O(n)。

容易错在：负数会破坏单调性；答案最多 n(n+1)/2，须用 long long；全零不能漏计。

</details>
