# difference · 批量训练排期

难度：L1。来源：原创教学题。

## 要交付什么

n 天初值为 0。输入 n m（1≤n≤200000，0≤m≤200000），随后 m 行 l r delta（1≤l≤r≤n，|delta|≤10^9）。每次给 [l,r] 加 delta；最后输出 n 天的数值。

## 自测样例（本仓库自编）

输入：
```text
5 2
1 3 2
3 5 -1
```
输出：
```text
2 2 1 -1 -1
```

<details><summary>提示与推导（先尝试再展开）</summary>

把变化记录在边界：d[l]+=delta，d[r+1]-=delta。前缀和恢复每一天的值。

复杂度：时间 O(n+m)，空间 O(n)。

容易错在：预留 r+1；操作过程中需要查询时不能只靠最后一次还原。

### 更详细的推演

**怎么想到：** 逐天给 [l,r] 加值很直观，但多次大区间操作会反复更新同一天。把变化只记在开始和结束后的边界，最后一次扫描还原。

**跟踪样例：** 初始差分全为 0。操作 [1,3]+2：d[1]+=2，d[4]−=2；操作 [3,5]−1：d[3]−=1，d[6]+=1。扫描 d[1..5] 累计为 2、2、1、−1、−1。

**关键细节：** d[r+1] 是撤销影响的位置，所以数组预留到 n+1；若错误写在 d[r]，区间最后一天就不生效。累计值要用 long long；n=1、m=0 输出 0。
