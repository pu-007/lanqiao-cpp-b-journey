# difference · 批量训练排期

难度：L1。来源：原创教学题。

## 要交付什么

n 天初值为 0。输入 n m（1≤n≤200000，0≤m≤200000），随后 m 行 l r delta（1≤l≤r≤n，|delta|≤10^9）。每次给 [l,r] 加 delta；最后输出 n 天的数值。

## 自测样例（本仓库自编）

输入：
```text
5 2
1 3 2
3 5 -1
```
输出：
```text
2 2 1 -1 -1
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start difference` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check difference --mine`；失败时先缩小反例。
5. 通过后再读 [difference.cpp](difference.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

把变化记录在边界：d[l]+=delta，d[r+1]-=delta。前缀和恢复每一天的值。

复杂度：时间 O(n+m)，空间 O(n)。

容易错在：预留 r+1；操作过程中需要查询时不能只靠最后一次还原。

</details>
