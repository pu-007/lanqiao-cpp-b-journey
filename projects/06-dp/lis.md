# lis · 能力增长曲线

难度：L3。来源：原创教学题。

## 要交付什么

输入 n（0≤n≤200000）和 n 个绝对值≤10^9 的整数，输出最长严格递增子序列长度。子序列不要求连续。

## 自测样例（本仓库自编）

输入：
```text
6
3 1 2 2 4 0
```
输出：
```text
3
```

<details><summary>提示与推导（先尝试再展开）</summary>

先推 O(n²)：dp[i]=1+max(dp[j])，要求 j<i 且 a[j]<a[i]。优化时 tails[len-1] 保存长度为 len 的递增子序列最小末尾。对新值用 lower_bound 替换首个≥它的位置。

复杂度：优化版时间 O(n log n)，空间 O(n)。

容易错在：严格递增用 lower_bound；非降用 upper_bound；tails 本身不一定是原序列的一条子序列。

### 更详细的推演

**怎么想到：** 先用 O(n²) 想清楚：以第 i 项结尾的最长长度，等于所有更早且更小项的最好长度加 1。优化版不保存所有方案，只保存每个长度所能达到的最小结尾 tails，结尾越小越方便将来接更大的数。

**跟踪样例：** 依次处理 3、1、2、2、4、0，tails 变化为 [3] → [1] → [1,2] → [1,2] → [1,2,4] → [0,2,4]；最长长度始终是 tails 的长度，最终为 3。

**关键细节：** 严格递增遇到相等元素时不能延长，因此使用 lower_bound 找首个大于等于当前值的位置并替换。tails 是各长度最小结尾的汇总，不一定本身是一条真实子序列；想输出路径需额外存前驱。
