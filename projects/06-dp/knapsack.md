# knapsack · 训练收益规划

难度：L3。来源：原创教学题。

## 要交付什么

输入 n B（1≤n≤200，0≤B≤10000），随后 n 行 cost value（1≤cost≤10000，0≤value≤10^9）。每项训练最多选择一次，总耗时不超过 B，输出最大收益。

## 自测样例（本仓库自编）

输入：
```text
3 5
2 3
3 5
4 6
```
输出：
```text
8
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start knapsack` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check knapsack --mine`；失败时先缩小反例。
5. 通过后再读 [knapsack.cpp](knapsack.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

dp[c] 表示已考虑的任务中、预算不超过 c 的最大收益。选当前任务来自上一层 dp[c-cost]+value，不选保持 dp[c]。压缩成一维后倒序更新，确保读取上一层。

复杂度：时间 O(nB)，空间 O(B)。

容易错在：正序更新会变成完全背包；恰好装满应把不可达状态设为负无穷。

</details>

- E06-B：改成恰好用完 B，无法完成输出 -1。

验收：能说明改变哪个约束会使当前算法失效，补一个原样例没有覆盖的边界。升级练习是开放扩展，不包含独立参考答案与自动评测；主任务有参考实现和本地测试。
