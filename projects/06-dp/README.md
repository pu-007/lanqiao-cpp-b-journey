## 项目交付

在时间预算中挑训练项目，并分析成绩的最长增长子序列。

这些是围绕同一场景逐步升级的命令行算法实验，不需要做 UI、数据库或 Web 服务。每个 `.cpp` 单独编译运行，便于直接迁移到竞赛的一题一文件模式。

## 实现里程碑

先写子集枚举，再列二维背包表，最后压缩空间；LIS 先做 O(n²)，再考虑 tails。

每个任务先完成题面主要求，再考虑两道升级练习。一天最多推进一个新模型。主线新任务建议 90–120 分钟；L4/L5 允许拆成两周。

## 验收门槛

每个状态的一句话定义是什么？转移为什么覆盖所有选择？

- 不看答案复述模型，并说明至少一个不适用的条件。
- 自己补三类边界；在 `practice/` 重写并通过本地测试。
- 写 100–200 字复盘，记录一条“为何想不到”的原因。
- 两天和一周后重做。只看懂注释不算完成。

本项目难度是教学排序，不是官方难度。周计划决定当前必做项；扩展题和进阶项目可留到省赛后。
