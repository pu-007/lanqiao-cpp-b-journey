# sieve · 素数查询服务

难度：L2。来源：原创教学题。

## 要交付什么

输入 N q（1≤N≤10^6，1≤q≤200000），然后 q 个 0..N 的整数，逐行输出是否为素数 YES/NO。

## 自测样例（本仓库自编）

输入：
```text
10 5
0 1 2 9 7
```
输出：
```text
NO
NO
YES
NO
YES
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start sieve` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check sieve --mine`；失败时先缩小反例。
5. 通过后再读 [sieve.cpp](sieve.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

埃氏筛从每个尚未标记的数 p 出发，划掉 p 的倍数。小于 p² 的倍数已有更小的质因子处理过。

复杂度：时间 O(N log log N+q)，空间 O(N)。

容易错在：0、1 不是素数；p*p 用足够大的类型或改为 p≤N/p。

</details>
