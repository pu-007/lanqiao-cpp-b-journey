# powmod · 大指数取模器

难度：L2。来源：原创教学题。

## 要交付什么

输入 a b m（0≤a≤10^18，0≤b≤10^18，1≤m≤10^9），输出 a^b mod m。本练习约定 a^0=1，包括 a=0。

## 自测样例（本仓库自编）

输入：
```text
2 10 1000
```
输出：
```text
24
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start powmod` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check powmod --mine`；失败时先缩小反例。
5. 通过后再读 [powmod.cpp](powmod.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

把 b 写成二进制。每次处理最低位，若为 1 就把当前底数乘入结果；底数平方、指数右移。先取模后两个因子都小于 10^9，乘积在 long long 内。

复杂度：时间 O(log(b+1))，空间 O(1)。

容易错在：m=1 时答案是 0；不是所有模数都能使用费马逆元。

</details>
