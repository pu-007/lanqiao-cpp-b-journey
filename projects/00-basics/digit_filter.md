# digit_filter · 数字筛选器

难度：L0。来源：原创教学题。

## 要交付什么

输入 N（1≤N≤10^6），统计 1..N 中十进制表示至少含一个 2 的整数个数。

## 自测样例（本仓库自编）

输入：
```text
25
```
输出：
```text
8
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start digit_filter` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check digit_filter --mine`；失败时先缩小反例。
5. 通过后再读 [digit_filter.cpp](digit_filter.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

枚举整数，再用 %10 提取末位、/10 删去末位。对每个数只返回一次真假，222 只能计数一次。

复杂度：时间 O(N log N)，空间 O(1)。

容易错在：不要在检查数字时破坏外层循环变量。

</details>
