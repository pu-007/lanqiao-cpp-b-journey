# subsets · 装备组合搜索

难度：L2。来源：原创教学题。

## 要交付什么

输入 n K（0≤n≤22，0≤K≤10^12），随后 n 个 0..10^9 的重量。每件装备最多选一次，求总重恰为 K 的子集数量，空集计入，等重装备仍是不同物品。

## 自测样例（本仓库自编）

输入：
```text
4 3
1 2 3 0
```
输出：
```text
4
```

<details><summary>提示与推导（先尝试再展开）</summary>

搜索第 i 件时只作选/不选两种决策；状态 (i,sum) 表示前 i 件决策已完成。只在叶子结算，避免有 0 时重复或漏计。

复杂度：时间 O(2^n)，递归栈 O(n)（另存输入 O(n)）。

容易错在：剪枝依赖重量非负；sum==K 不能直接返回，因为后续的 0 可产生更多方案。

### 更详细的推演

**怎么想到：** 每件装备只有“选”或“不选”两种选择。把所有选择画成二叉树，走到最后一件之后检查总重量；这些叶子恰好对应所有子集。

**跟踪样例：** 重量 1、2、3、0，目标 3。不考虑 0 时可选 `{1,2}` 或 `{3}`；对每个方案，最后重量 0 的装备又可选或不选，于是 2×2=4 个方案。

**关键细节：** `dfs(index,sum)` 中，前 index 件已决定，sum 是它们的总重量。只有所有数非负时，sum 已超过目标才能安全剪枝；sum 已等于目标也不能立刻返回，因为后续 0 还有选和不选两种方案。
