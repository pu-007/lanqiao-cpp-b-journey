# bridges · 网络关键边审计

难度：L5。来源：原创教学题。

## 要交付什么

输入 n m（1≤n≤200000，0≤m≤300000），m 条无向边，允许重边、自环。求桥的数量：删除该边会让连通块数量增加的边称为桥。

## 自测样例（本仓库自编）

输入：
```text
4 4
1 2
2 3
3 1
3 4
```
输出：
```text
1
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start bridges` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check bridges --mine`；失败时先缩小反例。
5. 通过后再读 [bridges.cpp](bridges.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

DFS 时间戳 tin[u]；low[u] 是 u 子树沿树边向下再经至多一条返祖边可到达的最小时间戳。树边 u-v 是桥当且仅当 low[v]>tin[u]。必须按边编号跳过父边，保留另一条平行边。实现使用显式栈。

复杂度：时间 O(n+m)，空间 O(n+m)。

容易错在：不能仅按父节点跳过所有平行边；必须遍历每个连通块；处理完孩子再更新父亲。
