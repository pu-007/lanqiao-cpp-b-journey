# offline_connectivity · 网络故障回放

难度：L4。来源：原创教学题。

## 要交付什么

输入 n m q（1≤n≤200000，0≤q≤m≤200000）；m 条无向边按 1..m 编号，随后 q 个不同的边编号，依次删除这些边。输出每次删除之后的连通块个数。允许重边和自环。

## 自测样例（本仓库自编）

输入：
```text
4 3 2
1 2
2 3
3 4
2 1
```
输出：
```text
2
3
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start offline_connectivity` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check offline_connectivity --mine`；失败时先缩小反例。
5. 通过后再读 [offline_connectivity.cpp](offline_connectivity.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

删边难维护，倒放时间后变成加边。先建“所有删除完成后的图”，逆序处理：先记录当前连通块数（对应这次删除之后），再把该边加回。

复杂度：时间 O((n+m+q)α(n))，空间 O(n+m+q)。

容易错在：题目限定每条边最多删一次；记录答案的时机是加回之前。
