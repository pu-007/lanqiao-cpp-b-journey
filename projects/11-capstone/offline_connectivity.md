# offline_connectivity · 网络故障回放

难度：L4。来源：原创教学题。

## 要交付什么

输入 n m q（1≤n≤200000，0≤q≤m≤200000）；m 条无向边按 1..m 编号，随后 q 个不同的边编号，依次删除这些边。输出每次删除之后的连通块个数。允许重边和自环。

## 自测样例（本仓库自编）

输入：
```text
4 3 2
1 2
2 3
3 4
2 1
```
输出：
```text
2
3
```

## 从重新计算到倒放时间

正向删除一条边后，可以重新遍历整张图数连通块，每次 O(n+m)，q 次就可能 O(q(n+m))。普通并查集擅长合并集合，却不能直接把一个集合拆开。这里所有删除操作在输入里已知，可以先把时间倒过来：从“全部删完”开始，一条条加回。

状态是当前剩余图的连通块个数。开始时每个点都是一个集合，把没有删除的边合并；然后逆序处理删除列表。只有两端原本不连通时，加边才让连通块数减少 1。

## 样例逐步推演

原始链为 `1—2—3—4`，正向先删除边 2（2—3），再删除边 1（1—2）。全部删除后剩边 3（3—4），有 `{1}`、`{2}`、`{3,4}` 共 3 块。

| 逆序动作 | 当下块数 | 保存/变化 |
| --- | ---: | --- |
| 准备加回边 1 | 3 | 先记录第二次删除后的答案 3 |
| 加回边 1 | 2 | {1} 与 {2} 合并 |
| 准备加回边 2 | 2 | 记录第一次删除后的答案 2 |
| 加回边 2 | 1 | 回到原始连通图 |

最后按正向顺序输出 `2,3`。若先加回再记录，就会把“删除之前”误当作“删除之后”。这里依赖离线已知全部操作且每条边最多删一次；若同一条边重复删除，必须重新定义操作语义并处理计数，不能直接照搬。

<details><summary>提示与推导（先尝试再展开）</summary>

删边难维护，倒放时间后变成加边。先建“所有删除完成后的图”，逆序处理：先记录当前连通块数（对应这次删除之后），再把该边加回。

复杂度：时间 O((n+m+q)α(n))，空间 O(n+m+q)。

容易错在：题目限定每条边最多删一次；记录答案的时机是加回之前。
