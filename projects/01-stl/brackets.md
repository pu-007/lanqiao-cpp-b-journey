# brackets · 括号检查器

难度：L1。来源：原创教学题。

## 要交付什么

输入一行仅包含 ()[]{} 的字符串，长度 0..200000；空行也有效。输出 YES 当且仅当所有括号正确匹配，否则 NO。

## 自测样例（本仓库自编）

输入：
```text
([]{})
```
输出：
```text
YES
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start brackets` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check brackets --mine`；失败时先缩小反例。
5. 通过后再读 [brackets.cpp](brackets.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

栈保存还没有被匹配的左括号。遇到右括号，只能和最近的左括号配对。

复杂度：时间 O(n)，空间 O(n)。

容易错在：读空串用 getline；栈空时不能调用 top/pop。
