# frequency · 日志词频分析

难度：L1。来源：原创教学题。

## 要交付什么

输入 n（1≤n≤100000）和 n 个只含小写字母的单词（长度≤30）。按字典序输出每种单词及出现次数，每种一行。

## 自测样例（本仓库自编）

输入：
```text
5
dp stl dp bfs stl
```
输出：
```text
bfs 1
dp 2
stl 2
```

<details><summary>提示与推导（先尝试再展开）</summary>

map 是有序键值映射。++count[word] 会把不存在的键插入并初始化为 0。unordered_map 不保证遍历顺序。

复杂度：时间 O(n log u)，空间 O(u)，u 是不同单词数（长度视为常数）。

容易错在：查询不存在的 key 时 operator[] 会插入；只查询存在性时使用 find。

### 更详细的推演

**怎么想到：** 想象一本记账本，左栏是单词，右栏是累计次数。每看到一个单词就把对应计数加一；map 遍历时会按键的字典序输出。

**跟踪样例：** 读 dp 后 `{dp:1}`；读 stl 后再多 `{stl:1}`；第二个 dp 变 2；bfs 变 1；最后 stl 变 2。输出顺序是 bfs、dp、stl，跟首次出现顺序不同。

**关键细节：** `++count[word]` 在单词首次出现时插入值为 0 的计数。若只是想检查一个键是否存在，`find` 不会插入；用 `count[word]` 查询却会创建这个键。
