# ranking · 训练排行榜

难度：L1。来源：原创教学题。

## 要交付什么

输入 n（1≤n≤200000），随后 n 行：name score。name 是不含空格的 ASCII 字符串，长度≤20；score 为 0..10^9。按分数降序、同分名字字典序升序输出每条记录。允许完全重复的记录。

## 自测样例（本仓库自编）

输入：
```text
4
zoe 90
ann 90
bob 100
ann 90
```
输出：
```text
bob 100
ann 90
ann 90
zoe 90
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start ranking` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check ranking --mine`；失败时先缩小反例。
5. 通过后再读 [ranking.cpp](ranking.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

vector 保存结构体，sort 接受“a 是否应该排在 b 前面”的比较器。相等时必须返回 false，不能使用 >=。

复杂度：时间 O(n log n)，空间 O(n)（含记录；名字长度视为常数）。

容易错在：比较器必须满足严格弱序；vector.reserve 不改变 size。

</details>

## 升级练习

- E01-A：同一用户多次提交只保留最高分，再排序。
- E01-B：新增名次，明确同分时是 1,1,3 还是 1,1,2。

验收：能说明改变哪个约束会使当前算法失效，补一个原样例没有覆盖的边界。升级练习是开放扩展，不包含独立参考答案与自动评测；主任务有参考实现和本地测试。
