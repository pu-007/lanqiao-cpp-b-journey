# intervals · 会议室预约

难度：L2。来源：原创教学题。

## 要交付什么

输入 n（0≤n≤200000），随后 n 行 s e（0≤s<e≤10^9）。区间是 [s,e)，求一间会议室最多安排多少场会议。

## 自测样例（本仓库自编）

输入：
```text
4
0 3
1 2
2 4
4 5
```
输出：
```text
3
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start intervals` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check intervals --mine`；失败时先缩小反例。
5. 通过后再读 [intervals.cpp](intervals.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

每次选结束最早的可行会议。交换论证：把最优方案的第一场替换为结束更早的一场，不会影响后续会议；对剩余会议重复。

复杂度：时间 O(n log n)，空间 O(n)。

容易错在：按开始时间或时长排序都不保证最优；端点相等可以衔接。
