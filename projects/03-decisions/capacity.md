# capacity · 最小运输容量

难度：L2。来源：原创教学题。

## 要交付什么

输入 n D（1≤D≤n≤200000）和 n 个 1..10^9 的包裹重量。按原顺序运输，每天运一段连续包裹；最多 D 天完成，求最小整数日容量。不可拆包裹。

## 自测样例（本仓库自编）

输入：
```text
5 3
1 2 3 4 5
```
输出：
```text
6
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start capacity` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check capacity --mine`；失败时先缩小反例。
5. 通过后再读 [capacity.cpp](capacity.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

先解决判定：给定容量 C，按顺序尽量装满一天，能否在 D 天内完成？C 增大不会使可行变不可行，因此二分第一个可行容量。下界 max(a)，上界 sum(a)。

复杂度：时间 O(n log(sum a))，空间 O(n)。

容易错在：不能排序改变运输顺序；二分的是答案而非数组下标；用 left+(right-left)/2。
