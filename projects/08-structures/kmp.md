# kmp · 日志模式匹配

难度：L3。来源：原创教学题。

## 要交付什么

输入两行非空的小写字母串 text 与 pattern，各长≤10^6。输出 pattern 在 text 中出现的次数，允许重叠。

## 自测样例（本仓库自编）

输入：
```text
aaaaa
aaa
```
输出：
```text
3
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start kmp` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check kmp --mine`；失败时先缩小反例。
5. 通过后再读 [kmp.cpp](kmp.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

pi[i] 表示 pattern[0..i] 的最长真前后缀长度。失配后把已匹配长度 j 调整为 pi[j-1]，继续利用已有匹配，不必回退文本指针。

复杂度：时间 O(n+m)，空间 O(m)。

容易错在：匹配完成后退到 pi[j-1]，才能统计重叠；真前缀不能等于整串。

</details>
