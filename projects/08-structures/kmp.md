# kmp · 日志模式匹配

难度：L3。来源：原创教学题。

## 要交付什么

输入两行非空的小写字母串 text 与 pattern，各长≤10^6。输出 pattern 在 text 中出现的次数，允许重叠。

## 自测样例（本仓库自编）

输入：
```text
aaaaa
aaa
```
输出：
```text
3
```

## 从暴力到更快的办法

朴素方法把 pattern 对齐 text 的每个位置，逐个比较；长度为 n、m 时最坏 O(nm)。例如 text 为很多个 `a` 加一个 `b`，pattern 也有许多 `a` 后接不同字符，会反复比较同一段。KMP 预先记录模式自身的重复结构；失配时利用已经比较过的内容，文本下标无需后退。

## 样例逐步推演

`pattern = aaa` 的 `pi` 数组为 `[0,1,2]`：例如前缀 `aaa` 的最长相等真前后缀是 `aa`，长度 2。这里“真”表示不能是整个字符串本身。

| 已读 text | 当前匹配长度 j | 动作 |
| --- | ---: | --- |
| a | 1 | 首字符匹配 |
| aa | 2 | 第二字符匹配 |
| aaa | 3 | 得到第 1 次匹配，随后 j 回退到 pi[2]=2 |
| aaaa | 3 | 第 2 次匹配，再回退到 2 |
| aaaaa | 3 | 第 3 次匹配 |

`j` 表示当前已经匹配的 pattern 前缀长度；失配时用 `pi[j-1]` 找下一个可尝试长度。一次完整匹配后不能一律清零：本样例中的相邻匹配有重叠，清零会漏掉后两次。本题 pattern 非空；若另一个题目允许空模式，必须先定义它出现多少次，不能直接照搬。

<details><summary>提示与推导（先尝试再展开）</summary>

pi[i] 表示 pattern[0..i] 的最长真前后缀长度。失配后把已匹配长度 j 调整为 pi[j-1]，继续利用已有匹配，不必回退文本指针。

复杂度：时间 O(n+m)，空间 O(m)。

容易错在：匹配完成后退到 pi[j-1]，才能统计重叠；真前缀不能等于整串。
