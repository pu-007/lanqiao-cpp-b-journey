# windowmax · 滑动峰值监控

难度：L3。来源：原创教学题。

## 要交付什么

输入 n k（1≤k≤n≤200000），再读 n 个绝对值≤10^9 的整数。输出每个长度 k 的连续窗口最大值。

## 自测样例（本仓库自编）

输入：
```text
6 3
1 3 -1 -3 5 3
```
输出：
```text
3 3 5 5
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start windowmax` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check windowmax --mine`；失败时先缩小反例。
5. 通过后再读 [windowmax.cpp](windowmax.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

双端队列存候选下标，值从队首到队尾严格递减。新元素更大且更晚过期，会支配队尾较小元素；队首即最大值。

复杂度：时间 O(n)，空间 O(n)（输入数组；队列 O(k)）。

容易错在：队列保存下标才能判断过期；每个下标最多进出各一次，内层 while 不意味着 O(n²)。

</details>
