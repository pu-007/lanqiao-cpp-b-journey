# fenwick · 实时训练报表

难度：L3。来源：原创教学题。

## 要交付什么

输入 n q（1..200000）、n 个绝对值≤10^9 的初值，再读 q 个操作：1 i delta 表示单点加（|delta|≤10^9）；2 l r 查询 [l,r] 的和。索引从 1 开始。

## 自测样例（本仓库自编）

输入：
```text
3 3
1 2 3
2 1 3
1 2 -5
2 2 3
```
输出：
```text
6
0
```

## 动手顺序

1. 先用纸笔推演样例，写出最直接的解法及操作次数。
2. 运行 `python3 scripts/lab.py start fenwick` 生成你的独立答题文件；不复制参考实现。
3. 独立思考 20–40 分钟。卡住时只展开下面提示。
4. 运行 `python3 scripts/lab.py check fenwick --mine`；失败时先缩小反例。
5. 通过后再读 [fenwick.cpp](fenwick.cpp)，口述正确性与复杂度；2 天后关掉答案重写。

<details><summary>提示与推导（先尝试再展开）</summary>

树状数组 tree[i] 管理以 i 结尾、长度为 lowbit(i) 的块。前缀查询不断扣掉最后一块；单点更新沿包含它的更大块传播。

复杂度：时间 O((n+q) log n)，空间 O(n)。

容易错在：i=0 的更新会死循环；区间加值不是普通单点加模型。

</details>
